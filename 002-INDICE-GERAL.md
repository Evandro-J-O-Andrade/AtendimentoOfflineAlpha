## Regra de Navegação

```text
1. Sempre comece pelo Bootstrap.
2. Nunca entre em código sem ler a documentação correspondente.
3. Se encontrar documento faltando, crie-o antes de implementar.
4. Se encontrar divergência entre documentos, pare e reporte.
5. Nunca use código legado como referência de implementação.
6. Documentação é a fonte de verdade. Código é consequência.
```
