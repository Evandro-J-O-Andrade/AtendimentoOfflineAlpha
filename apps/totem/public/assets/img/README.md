# Imagens do Totem

Este diretório deve conter as imagens usadas pelo Totem:

- `prefeitura.png` — Logo da prefeitura
- `sistema.png` — Logo do sistema/Alpha
- `prioritario.jpg` — Ícone ou imagem para atendimento prioritário
- `pediatrico.png` — Ícone ou imagem para pediatria
- `normal.png` — Ícone ou imagem para atendimento normal

## Placeholder
