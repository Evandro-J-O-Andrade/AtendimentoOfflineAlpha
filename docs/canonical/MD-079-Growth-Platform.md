## Regras

1. Todo ciclo de campanha é registrado no Event Store.
2. Nenhuma comunicação sem consentimento explícito.
3. Opt-out é respeitado em todos os canais.
4. Performance é medida por experimentação (A/B).
5. IA otimiza, humanos aprovam estratégia.
6. Dados de growth alimentam Customer 360 continuamente.
