# MATRIZ-DOMINIOS

## Propósito

Documento único de mapeamento entre módulos/domínios e COREs/MAPs/MDs.

## Formato

| Domínio | MAP | MD | CORE(s) |
|---------|-----|----|---------|
| Portal | MAP-005 | MD-006 | CORE-003, CORE-005 |
| Identidade | MAP-003 | MD-002 | CORE-001 |
| Contexto | MAP-004 | MD-003 | CORE-002 |
| Permissões | MAP-006 | MD-004 | CORE-004 |
| ...

## Regra

Cada módulo novo deve ser registrado aqui antes de implementação.

Nenhum módulo pode ser considerado completo sem:
- MAP
- MD
- CORE correspondente
- Testes

## Atualização

Atualizada pelo arquiteto após criação de novo domínio.
