# LOGIN

O login pertence à plataforma.

O login NÃO pertence:

- ao tenant
- à unidade
- ao setor
- ao contexto operacional

# PORTAL CORPORATIVO

O Portal é a Home oficial.

Todo usuário autenticado deve passar pelo Portal.

Nunca redirecionar diretamente para aplicações operacionais.
