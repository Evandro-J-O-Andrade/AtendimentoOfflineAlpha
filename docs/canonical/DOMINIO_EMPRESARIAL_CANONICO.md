## Lei Imutável do Domínio Assistencial

```
Pessoa
→ Senha
→ FFA
→ GPAT
→ Eventos
```

**A Pessoa é a entidade raiz.**

**A Senha inicia o episódio assistencial.**

**A FFA é o container operacional.**

**O GPAT identifica o episódio.**

Todo o restante da plataforma se integra a este fluxo quando houver contexto assistencial.
