# DIVIDA-TECNICA

## Propósito

Registro único de dívidas técnicas da plataforma.

## Formato

| ID | Item | Motivo | Impacto | Prioridade | Dependências | Status |
|----|------|--------|---------|------------|--------------|--------|
| DT-001 | sp_auth_permissions_evaluate | SQL não aplicado | CORE-005 bloqueada | Alta | Nenhuma | Aberta |
| ...

## Regra

Nenhuma dívida técnica pode ser "esquecida".

Toda dívida deve ser:
- registrada aqui
- classificada
- acompanhada

## Atualização

Atualizada pelo arquiteto após identificação de nova dívida.
