# DASHBOARD-MATURIDADE

## Propósito

Painel visual de maturidade da plataforma.

## Formato

| Área | Maturidade |
|------|:----------:|
| Banco | 95% |
| Backend | 70% |
| Runtime | 60% |
| Frontend | 75% |
| Segurança | 55% |
| Auditoria | 40% |
| Testes | 30% |
| Documentação | 92% |

## Regra

Atualizado após cada CORE ou gate relevante.

Maturidade é calculada pela média de:
- implementação
- testes
- auditoria
- documentação

## Atualização

Atualizada pelo arquiteto após conclusão de cada CORE.
